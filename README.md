# TP Rust — Module 1 : Fondations

## Structure

```
tp-rust-module1/
├── tp1-calculatrice-cli/   # Séance 1 — Setup & CLI
├── tp2-gestion-memoire/    # Séance 2 — Ownership sans références
├── tp3-analyseur-chaines/  # Séance 3 — Références & Slices
└── tp4-processus-os/       # Séance 4 — Structs, Enums, Pattern Matching
```

## Comment travailler

```bash
# Entrer dans un TP
cd tp1-calculatrice-cli

# Compiler
cargo build

# Exécuter
cargo run

# Lancer les tests (TP3)
cargo test

# Vérifier le style
cargo clippy
cargo fmt
```

## Rendu

Poussez votre travail sur votre branche dédiée :
```bash
git add .
git commit -m "TP1 : calculatrice CLI terminée"
git push origin main
```

> Chaque TP est indépendant. Travaillez-les dans l'ordre.
